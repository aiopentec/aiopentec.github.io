Meta Titles & Descriptions

Produces ten meta title and description pairs for one page, each within character limits and built around a different emotional trigger, so you can A/B the one that actually gets clicked in search results.

Best for: SEO-minded site owners optimizing click-through rate on pages that already rank but don't get clicked.

PROMPT Nº 08 OF 37

Create 10 variations of SEO meta titles and descriptions for:

  • PAGE TOPIC: [your topic]
  • TARGET KEYWORD: [keyword]
  • BUSINESS/SITE: [your business]
For each variation provide:
  • Title (55-60 characters, include keyword)
  • Description (150-155 characters, include keyword + CTA)
  • Emotional trigger used (curiosity/urgency/benefit/social proof)

Make them click-worthy while staying honest and relevant.

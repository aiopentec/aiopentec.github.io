Problem Solving

Root Cause Analysis

Runs a real problem through the Five Whys method to find the actual root cause, then proposes three solutions at different time horizons with implementation steps and risks for each.

Best for: Anyone troubleshooting a recurring problem at work who suspects the obvious fix isn't actually fixing anything.

PROMPT Nº 35 OF 37

Help me solve this problem: [DESCRIBE PROBLEM]

PROBLEM DETAILS:
  • What's happening: [symptoms]
  • When it started: [timeline]
  • Who's affected: [people/dept/customers]
  • What we've tried: [past solutions]
  • Current impact: [cost/time/quality]
ANALYZE USING 5 WHYS:
  • Problem: [state it]
  • Why? [first reason]
  • Why? [dig deeper]
  • Why? [deeper still]
  • Why? [keep going]
  • Root cause: [the real issue]
Then provide:
  1. Root Cause Summary
  2. 3 Potential Solutions (short/med/long term)
  3. For each solution:
    • Implementation steps
    • Resources needed
    • Timeline
    • Risks
    • Expected outcome
  4. Recommended approach (which solution and why)

Be systematic and thorough.

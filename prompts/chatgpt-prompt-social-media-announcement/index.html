Social Media

Single Post Variations

Takes one announcement — a launch, a new hire, a milestone — and rewrites it five ways: LinkedIn-formal, Instagram-casual, X-punchy, Facebook-friendly, and a 30-second TikTok script, each tuned to how that platform actually reads.

Best for: Anyone who has one piece of news to share everywhere and doesn't want to write five separate posts by hand.

PROMPT Nº 04 OF 37

I need to announce [ANNOUNCEMENT: new service/product/hire/milestone].

Create 5 different versions of this announcement for:

  1. LinkedIn (professional tone, 200 words)
  2. Instagram (casual, visual, emojis, 150 chars)
  3. Twitter/X (punchy, 280 chars max)
  4. Facebook (friendly, longer form, 250 words)
  5. TikTok script (conversational, 30-second video)
  • Key points to include: [list 3-5 key points]

Make each platform-optimized and ready to post.
